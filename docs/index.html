Coverage & limitations

Correlations are shared source evidence, not proof of root cause.

Java/C# source binding runs with an isolated classpath; project builds and external dependencies are not evaluated.

Python compatibility is import-only and lexical; the previous Python AST implementation is retained in Git history, not in this runtime.

Test candidates are source-reachable, not measured coverage.

Redaction is best effort. Inspect reports before sharing.

RevScope recommends tools; no binary analysis is executed.

How ForgeScope works

Follow seven practical steps from setup to a report. Expand a step to copy the exact commands.

01Explore the sample

Click Start demonstration to walk through overview, impact, tests, references, findings and limitations.

Open guided tour
02Install requirements

Install JDK 21, .NET 10 SDK and Git. These are needed on your computer, not on GitHub Pages.

03Clone and build

Run this block in a terminal. The Java CLI, Roslyn worker and ASP.NET workbench will be built.

git clone https://github.com/brunnojob/forgescope.git
cd forgescope
dotnet build dotnet/ForgeScope.Worker -c Release
dotnet build dotnet/ForgeScope.Workbench -c Release
java tools/Build.java
04Run a sample scan

Analyze the bundled Java/C# fixture, supplied patch and CI log. Results are written to .forgescope.

java -jar build/forgescope.jar examples/sample --changed java/src/shop/Pricing.java --changed csharp/Pricing.cs --diff examples/change.diff --log examples/build.log --csharp-worker dotnet/ForgeScope.Worker/bin/Release/net10.0/ForgeScope.Worker.dll --output .forgescope
05Read the report

Open the generated HTML in a browser. Check affected files, candidate tests, engine status, compiler evidence and limitations.

.forgescope/index.html

06Open the local workbench

Start ASP.NET Core and open http://127.0.0.1:8765. Filter findings and rescan only the repository configured at startup.

dotnet dotnet/ForgeScope.Workbench/bin/Release/net10.0/ForgeScope.Workbench.dll --report .forgescope/report.json --repo examples/sample --jar build/forgescope.jar --worker dotnet/ForgeScope.Worker/bin/Release/net10.0/ForgeScope.Worker.dll
07Review and export

Use JSON, SARIF or Markdown after reviewing the evidence. Potential impact is not proof of a defect; reports may contain sensitive paths or snippets.

Pages displays example evidence. Actual scans use Java and .NET locally; the offline report works without JavaScript.
