Cobertura y limitaciones

Las correlaciones indican evidencias en el mismo código, no demuestran la causa raíz.

La resolución Java/C# usa un entorno aislado; no se evalúan compilaciones del proyecto ni dependencias externas.

La compatibilidad con Python es léxica y se limita a imports; la implementación AST anterior está en el historial Git, no en esta ejecución.

Las pruebas candidatas tienen relaciones en el código; esto no mide cobertura.

La ocultación de datos sensibles puede ser incompleta. Revisa los informes antes de compartirlos.

RevScope sugiere herramientas; no se ejecuta ningún análisis binario.

Cómo funciona ForgeScope

Sigue siete pasos prácticos desde la instalación hasta el informe. Despliega cada paso para copiar los comandos exactos.

01Explora el ejemplo

Pulsa Iniciar demostración para recorrer resumen, impacto, pruebas, referencias, hallazgos y limitaciones.

Abrir recorrido guiado
02Instala los requisitos

Instala JDK 21, SDK .NET 10 y Git. Se necesitan en tu equipo, no en GitHub Pages.

03Clona y compila

Ejecuta este bloque en la terminal. Se compilarán la CLI Java, el worker Roslyn y el panel ASP.NET.

git clone https://github.com/brunnojob/forgescope.git
cd forgescope
dotnet build dotnet/ForgeScope.Worker -c Release
dotnet build dotnet/ForgeScope.Workbench -c Release
java tools/Build.java
04Ejecuta un análisis de ejemplo

Analiza el ejemplo Java/C#, el parche y registro de CI incluidos. Los resultados se guardarán en .forgescope.

java -jar build/forgescope.jar examples/sample --changed java/src/shop/Pricing.java --changed csharp/Pricing.cs --diff examples/change.diff --log examples/build.log --csharp-worker dotnet/ForgeScope.Worker/bin/Release/net10.0/ForgeScope.Worker.dll --output .forgescope
05Lee el informe

Abre el HTML generado en el navegador. Revisa archivos afectados, pruebas candidatas, estado de los motores, evidencias del compilador y límites.

.forgescope/es.html

06Abre el panel local

Inicia ASP.NET Core y visita http://127.0.0.1:8765. Filtra hallazgos y analiza de nuevo solo el repositorio configurado.

dotnet dotnet/ForgeScope.Workbench/bin/Release/net10.0/ForgeScope.Workbench.dll --report .forgescope/report.json --repo examples/sample --jar build/forgescope.jar --worker dotnet/ForgeScope.Worker/bin/Release/net10.0/ForgeScope.Worker.dll
07Revisa y exporta

Usa JSON, SARIF o Markdown tras revisar las evidencias. El impacto potencial no demuestra un fallo; los informes pueden contener rutas o fragmentos sensibles.

Pages muestra evidencias de ejemplo. Los análisis reales usan Java y .NET localmente; el informe offline funciona sin JavaScript.
