Cobertura e limitações

As correlações indicam evidências no mesmo código, não comprovam a causa raiz.

A resolução Java/C# usa um ambiente isolado; builds do projeto e dependências externas não são avaliados.

A compatibilidade com Python é lexical e limitada a imports; a implementação AST anterior está no histórico Git, não nesta execução.

Os testes candidatos têm relações no código; isso não mede cobertura.

A ocultação de dados sensíveis pode ser incompleta. Revise os relatórios antes de compartilhar.

O RevScope sugere ferramentas; nenhuma análise binária é executada.
